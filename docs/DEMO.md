# 评审演示指南

> 面向评审专家：按下面顺序点一遍，大约 8 分钟，能覆盖赛题要求的六大模块与三个官方测试用例。
> 如果使用在线演示地址，文献库已预置 9 篇论文与索引，可直接从第 2 步开始。

## 0. 环境

- 本地：`& .\scripts\start.ps1` → 打开 http://localhost:3000（首次约 20 秒加载模型）
- 在线：（部署后填写地址）
- 无需登录。

## 1. 官方用例 A：语义去重与版本演进

1. 左侧「＋ 导入 PDF」上传 `pdf/1706.03762v7.pdf`，等待解析完成。
2. 再上传 `pdf/1706.03762v1.pdf`。
3. **预期**：右下角弹出预警——判定 `same_work`，正文重合度约 0.90，提示"库中已有更新版本（v7），建议保留"。
4. 点击「两个都留」或「保留库中版本」，观察文献列表变化。
5. 若要单独查看修订差异，可调用 `GET /api/documents/{旧id}/diff/{新id}`，返回按章节对齐的增删改摘要。

## 2. 官方用例 B：扫描件解析

1. 上传 `pdf/1706.03762v1_img.pdf`（纯图片、无文本层）。
2. **预期**：解析耗时明显长于矢量 PDF（约 2 分钟），完成后标题、7 个章节、36 条参考文献齐全，头部标签显示「扫描件 OCR」。
3. 打开「章节树」核对层级；打开「参考文献」核对条目。

## 3. 官方用例 C：长文档

1. 上传 `pdf/UnderstandingDeepLearning_02_09_26_C.pdf`（541 页）。
2. **预期**：约 30 秒完成，内存占用稳定；「章节树」可展开三级标题。
3. 该文档体量较大，提问会先触发建索引，界面会显示"正在建立检索索引"。

## 4. 抗幻觉问答（模块②）

1. 选择 `Attention Is All You Need`，在右侧面板问：**"训练用了多少块 GPU、什么型号？"**
   - 预期：回答"8 块 NVIDIA P100"，并带 `[c2]` 一类引用芯片；点芯片跳到原文对应页并高亮。
2. 换一篇 `Language Models are Few-Shot Learners`（GPT-3），问同一问题。
   - 预期：**拒答**——"证据中只提到 V100，没有给出数量，因此无法回答"。这是抗幻觉的关键演示点。
3. 问：**"这篇论文最大的模型有多少参数？"**
   - 预期：175 billion parameters，带引用。

## 5. 跨文献对比（模块②）

1. 在任意文档下切到「跨文献对比」页签。
2. 默认已勾选 **BERT** 与 **Attention Is All You Need**（承袭关系最典型的一对）。
3. 点「对比这 2 篇」。
4. **预期**：结论先行 + 按维度（架构来源、实现一致性、基本构件、注意力方向）展开，用表格呈现；每个结论带 `[cN]`，右侧按文档分组列出证据，点击可跳到对应论文的对应页。
5. 若只想看某几篇，可自行勾选 2–5 篇，再点预设问题。

## 6. 对照翻译与划词翻译（模块③）

1. 切到「对照」页签。
2. 首次进入需要生成译文（本地 MT 约 2–3 分钟；配置了 LLM Key 会快且质量更好）。
3. **预期**：左英右中，按段落对齐；拖动任一侧，另一侧滚到同一段；点击任一段落跳到 PDF 对应位置。\n4. 回到「阅读」页签，用鼠标**划选一句英文**。\n5. **预期**：选区旁弹出译文气泡（1-2 秒）；同一句再划一次直接命中缓存。

## 7. 引用图谱与综述（模块⑤）

1. 点左侧「引用图谱」。
2. **预期**：约 33 个节点、52 条边的有向图；红点为基石论文（Adam、Attention、LayerNorm 等）。
3. 右侧"自动综述"由图谱统计生成，含基石、衍生、时间跨度与待探索方向。

## 8. 检索与推荐（模块④）

1. 点左侧「检索发现」。
2. 检索 `all:retrieval augmented generation`。
3. **预期**：结果按"库内相关性 / 开源代码 / 时效"重排，每条显示相关度与理由；带代码的论文有「代码」链接。
4. 点「下钻入库」，观察它自动下载、解析、去重、入库。
5. 点右侧「按库内偏好刷新」，查看个性化推荐。

## 9. 写作 Copilot（模块⑥）

1. 点左侧「写作 Copilot」。
2. 「论文框架」输入一个想法（如"用检索增强降低学术问答幻觉"），点生成。
3. **预期**：输出 Abstract / Introduction / Related Work；右侧列出被引用的库内文献，正文编号与之一一对应；若模型引用了不存在的编号，会被剔除并在顶部提示。
4. 切「数据图表」，上传 `scripts/samples/model_bleu.csv`。
5. **预期**：自动拆成上下两个子图（BLEU 与参数量量级差 20 倍），并给出含峰值与趋势的图注。
6. 切「架构图脚本」，生成 Mermaid / TikZ / Graphviz 三份脚本。

## 10. 一键复现（命令行）

```bash
python scripts/parse_probe.py pdf/1706.03762v7.pdf   # 解析指标
python scripts/eval_retrieval.py                     # 检索评测 6/6
python scripts/dedupe_test.py                        # 去重与版本差异
python scripts/graph_probe.py                        # 图谱与综述
python scripts/writing_probe.py                      # 图表与框架
```

## 常见问题

| 现象 | 说明 |
|---|---|
| 首次提问等 20 秒 | BGE-M3 首次加载；之后正常 |
| 回答开头写"抽取式回答" | 未配置 `LLM_API_KEY`，属预期降级 |
| 图谱节点很少 | 库内文献太少；建议先 `python scripts/seed_demo.py` |
| 译文质量一般 | 未配置 Key 时走本地 MT，属预期降级 |
